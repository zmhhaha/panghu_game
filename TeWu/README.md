# 特务（TeWu）

《特务》是一个浏览器端身份辨识游戏原型。玩家选择盖世太保、克格勃、军统、中统或中央情报局，进入允许历史参考混合的机构设定。游戏包含两种玩法：执行官盘查十名 NPC，或扮演潜伏者接受审查官 Agent 的十轮追问。CIA 线的目标群体按本作设定为美国共产主义分子。

## 运行

需要 Python 3。进入当前目录后运行：

```powershell
npm run dev
```

然后访问 `http://localhost:4173`。也可以直接打开 `index.html`，但使用本地服务器时 SVG 素材和浏览器存档行为更稳定。

## 当前实现边界

- `WorldController` 是主控 Agent 的本地确定性模拟，持有机构设定、混合历史参考、NPC 隐藏真值、轮数和结算权。
- `NpcAgent` 是十个相互隔离的角色 Agent 模拟，每个角色拥有自己的十轮记忆和档案约束。
- `InfiltratorController` 和 `JudgeAgent` 提供潜伏者模式：玩家输入回答，审查官依据可疑度自动决定放行或扣留。
- 当前 `NpcAgent.respond()` 会根据玩家问题识别身份、路线、证件、关系、本地细节、目的和压力等主题，并结合角色档案、已回答内容和压力轮次生成角色化回答；它仍是本地确定性 Agent 模拟，后续可替换成服务端模型调用。
- 会话写入浏览器 `localStorage`，刷新页面可以恢复当前 NPC、轮数、对话和已完成判断。

玩法和历史内容边界见 [GAME_PLAN.md](GAME_PLAN.md)。
