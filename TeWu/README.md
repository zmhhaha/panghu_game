# 特务（TeWu）

《特务》是一个浏览器端身份辨识游戏原型。玩家选择盖世太保、克格勃、特高科或中央情报局，进入允许历史参考混合的机构设定。游戏包含两种玩法：执行官盘查十名 NPC，或扮演潜伏者接受审查官 Agent 的十轮追问。特高科线聚焦思想审查与出版监控，CIA 线采用麦卡锡主义时期的忠诚调查与反共审查背景，目标群体按本作设定为美国共产主义分子。

## 运行

需要 Python 3。进入当前目录后运行：

```powershell
npm run dev
```

然后访问 `http://localhost:4173`。也可以直接打开 `index.html`，但使用本地服务器时 SVG 素材和浏览器存档行为更稳定。

## 当前实现边界

- `WorldController` 是主控状态机，持有机构设定、混合历史参考、NPC 隐藏真值、轮数和结算权；候选人回应由 `tewu-server` 通过真实 LLM 生成。
- `NpcAgent` 是十个相互隔离的角色状态容器，每个角色拥有自己的不限轮数长期记忆、关系事件视角和档案约束。
- 执行官模式每局随机生成 2 至 4 名目标，并为每名目标预先生成可复核冲突、为每名普通人生成异常闭环；重复追问或机构核验会触发这些固定事实，模型不能临场抹平冲突。
- 机构核验对所有人使用相同的中性记录格式，只公开核验类别、原始记录和已有口供；目标 Agent 必须透露预生成事实，但不得主动承认自己前后矛盾。随机身份对应的核验要点和普通人闭环会随本局重新生成。
- 执行官结算使用目标命中率和普通人正确放行率各占一半的平衡分；全部放行或全部扣留都只能得到 50 分。
- `InfiltratorController` 和 `JudgeAgent` 提供潜伏者模式：玩家输入回答，审查官依据可疑度自动决定放行或扣留。
- 前端把当前角色的档案、关系事件视角和历史口供发送给 `tewu-server`；服务端最多重试三次真实模型请求。三次失败时不生成替代台词，只提示“模型正在忙，请稍后再提问”，并保留输入草稿。
- 会话写入浏览器 `localStorage`，刷新页面可以恢复当前 NPC、轮数、对话和已完成判断。

玩法和历史内容边界见 [GAME_PLAN.md](GAME_PLAN.md)。
