# 《潜伏》战役线索攻略

> 本文包含完整剧透，用于测试剧本的线性解谜流程。正式面向玩家时，可拆分为新手提示、章节提示和隐藏攻略。

## 阅读方式

每条路线都遵循同一原则：先用公开身份完成工作，再通过公开往来认识人物和地点，最后从多名人物处交叉核验情报。不要把“认识”当成“可信”，也不要在第一轮对话就索取核心情报。

---

## 一、临江潜线：第三号电台

### 1. 三个公开身份

| 身份 | 起点 | 第一位联系人 | 主要公开活动 |
| --- | --- | --- | --- |
| 机要处档案员 | 机要楼档案科 | 陈敬文 | 整理档案、值班、提交报告 |
| 南北货行商 | 江海饭店 | 罗伯安 | 对账、拜访客户、核验库存 |
| 自由撰稿人 | 临江日报社 | 林若岚 | 交稿、采风、校对稿件 |

三条路线最终会汇合到同一张临江线索网，但第一批公开引介不同。玩家应优先完成身份相关工作，避免一次行动同时触发多个主动事件。

### 2. 地点与人物解锁图

#### 档案员路线

`机要楼档案科`
→ 整理运输档案
→ `电讯科 / 周启明`
→ 核对设备交接记录
→ `三号码头 / 赵福生`
→ 核对运输回执
→ `江海饭店 / 沈曼秋、罗伯安`
→ 追查秘密会面和伤员联络
→ `老吴钟表店 / 老吴`
→ 确认备用交通线。

#### 行商路线

`江海饭店`
→ 商会对账与客户拜访
→ `三号码头 / 赵福生`
→ 追查货运路线
→ `老吴钟表店 / 老吴`
→ 通过钟表零件核对交通线
→ `机要楼档案科 / 陈敬文`
→ 取得公开档案核验理由
→ `电讯科 / 周启明`
→ 核对设备与发报窗口。

#### 撰稿人路线

`临江日报社`
→ 采风、校对公开消息
→ `江海饭店 / 罗伯安、沈曼秋`
→ 核对商会和伤员传闻
→ `三号码头 / 赵福生`
→ 追查货运见闻
→ `机要楼档案科 / 陈敬文`
→ 核对档案出处
→ `电讯科 / 周启明`
→ 确认设备和收报窗口。

### 3. 三项连续任务

#### 第一任务：确认无线电设备运输

必须形成三组互相印证的情报：

- `运输时间`：陈敬文、赵福生；
- `运输地点`：赵福生、林若岚；
- `货物内容`：陈敬文、周启明。

完成后发送电报，敌方会扩大清查，韩世杰开始关注玩家的公开行踪。

#### 第二任务：查明特务机关清查部署

需要收集：

- `档案借阅核查`：陈敬文、韩世杰；
- `临时封锁命令`：林若岚、韩世杰；
- `押运名单`：陈敬文、韩世杰。

这一步会解锁老吴和沈曼秋，并开放钟表店、江海饭店的更深层线索。情报不足时不要急着发送，优先通过对话核对来源和时间。

#### 第三任务：保全交通线并组织撤离

需要收集：

- `敌方重点监视名单`：林若岚、韩世杰；
- `交通线搜捕计划`：老吴、沈曼秋；
- `人员撤离路线`：赵福生、罗伯安。

完成后应切断暴露联络线，分批转移人员，再进行最终结算。

## 二、雾港暗线：失踪的药箱

### 1. 三个公开身份

| 身份 | 起点 | 第一位联系人 | 主要公开活动 |
| --- | --- | --- | --- |
| 港务凭证核验员 | 海州港务档案室 | 徐廷舟 | 核对船票、封签和交接凭证 |
| 码头药材经纪人 | 永泰商行 | 何锦顺 | 进货、验货、结账和拜访客户 |
| 晨报外勤采编 | 海州晨报社 | 乔云舒 | 采访、采风、核稿和交稿 |

三种身份的第一位联系人不同，但都能通过公开工作逐步接入同一张“药箱失踪—伪证诱捕—南汊撤离”线索网。

### 2. 地点与人物解锁图

#### 港务凭证核验员路线

`海州港务档案室`
→ 核对托运票和封签
→ `东平码头车站 / 陆小满`
→ 发现“买票但没有上车”的旅客
→ `济生药房 / 方致远`
→ 核对药箱封签与药材用途
→ `海关七号仓 / 蔡淑梅`
→ 核对入仓和换封条记录
→ `永泰商行 / 何锦顺`
→ 追查无主货箱。

#### 码头药材经纪人路线

`永泰商行`
→ 对账和客户拜访
→ `济生药房 / 方致远`
→ 核对药材订单
→ `东平码头车站 / 陆小满`
→ 核对托运行程
→ `海关七号仓 / 蔡淑梅`
→ 核对货箱和封条
→ `海州港务档案室 / 徐廷舟`
→ 补办公开凭证并追查删改记录。

#### 晨报外勤采编路线

`海州晨报社`
→ 采访和校对启事
→ `东平码头车站 / 陆小满`
→ 核对失踪旅客
→ `临河茶楼 / 段明礼`
→ 从说书和客人来往中交叉核验
→ `永泰商行 / 何锦顺`
→ 核对商情校样与货单
→ `海关七号仓 / 蔡淑梅`
→ 核对夜班入仓数字。

完成第一阶段后，方致远会引出南汊摆渡人关伯；这是第三任务的关键联系人，不应在开局直接寻找。

### 3. 三项连续任务

#### 第一任务：查明失踪药箱去向

需要收集：

- `失踪托运人的行程`：徐廷舟、乔云舒、陆小满；
- `急救药箱标记`：何锦顺、方致远、蔡淑梅；
- `药箱转移去向`：陆小满、蔡淑梅、魏宗海。

发送完整情报后，缉私科会扩大对通行证、货栈封条和报社启事的倒查。

#### 第二任务：揭开伪证诱捕计划

需要收集：

- `伪造通行证批次`：徐廷舟、蔡淑梅；
- `诱捕会面安排`：乔云舒、段明礼、魏宗海；
- `敌方观察对象`：陆小满、方致远、魏宗海。

茶楼会面地点是高风险诱饵。确认地点和时间前，不要把未核实的消息传给其他同志。

#### 第三任务：重建南汊交通线

需要收集：

- `南汊巡逻空档`：关伯、陆小满、段明礼；
- `撤离人员次序`：方致远、乔云舒、蔡淑梅；
- `备用无线电联络`：关伯、徐廷舟、何锦顺。

在第二任务结算后，南汊水路会进入封锁状态，关伯才会主动提出更换旧暗号。完成新暗号、撤离顺序和备用电台核验后，再进行最终结算。

## 通用解谜原则

1. 每条关键情报至少找两个来源交叉核验；单一来源只能作为线索，不能作为结论。
2. 先完成公开身份工作，再安排秘密对话；公开记录是应对盘查的保护层。
3. NPC 的主动谈话是剧情推进信号，不等于对方可靠。先询问来源、时间、在场人员和动机。
4. 地点和人物显示为“？？？”时，沿着已知人物的公开引介继续推进，不要直接搜索未知地点。
5. 任务结算前检查情报板：字段齐全、可信度达标、传递方式可用，并确认没有矛盾信息。
6. 完成一项任务后，敌方压力会变化，下一项任务的盘查和可行动窗口也会随之改变。
